# sweatshop-toy-strings

A deliberately tiny, dependency-free Bun library used as a **toy target** for
[Sweatshop.js](https://github.com/Uprising-Solutions/sweatshopjs) repository-intake tests.
`bun test` fails on `main` on purpose: `slugify` and `truncate` have bugs for agents to fix.

Not a real library. Do not depend on it.
